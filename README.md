# BusinessOS (Project Orion)

An AI-powered Business Operating System for small and growing businesses — unifying procurement, inventory, accounting, invoicing/payments, CRM, HR, and business intelligence into a single connected platform.

See [`documentation/concept-overview.md`](documentation/concept-overview.md) for the full product vision.

## Repository Structure

```
BusinessOS/
├── frontend/         # Web application (customer-facing UI)
├── backend/          # API and core business logic services
├── mobile/           # Mobile applications
├── infrastructure/   # IaC, deployment configs, CI/CD
├── documentation/     # Product, architecture, and process docs
└── scripts/          # Dev tooling and automation scripts
```
